# 配置・描画ルールの優先順位

対象は現在検証しているsbml2map開発版です。
[試験ページ](https://elixir2026-project22.github.io/sbml2map/test-tca/?v=e5358ef)と
[対応コード](https://github.com/elixir2026-project22/sbml2map/tree/e5358ef)を公開しています。
このMetNetCompリポジトリの従来コードには未同期の変更があります。現在の実装は上記の対応コードを参照してください。

## 必ず守る条件

1. **元モデルの意味を変えない。**
   代謝物・反応・係数・方向を保持します。存在しない化学種や反応を追加しません。
   表示用の接続口と配線の曲がり角は、元の生物学的ノード・接続に属する描画要素です。

2. **オレンジ線を、ノード記号の外で重ねない。**
   同じ反応の異なる接続線も対象です。点でのオレンジ同士の交差は許可します。
   5本以上の接続が集まるノードでは、中心の4方向だけでは線を分けられないため、記号内に接続口を分けます。
   記号内の短い接続部分と、記号外の配線の重なりを分けて記録・検証します。
   接続口の範囲は中心から各軸0.25グリッド以内、覆う記号の半径は0.36グリッドです。

3. **グリッド線を基本に配線し、細い通路は2本までにする。**
   横線のy座標、縦線のx座標を整数に合わせます。TCA回路そのものの円弧は例外です。
   整数グリッドで配線できない箇所には、0.25・0.75の位置に細い補助通路を使えます。
   同じ幅1グリッドの通路を並行して使うオレンジ線は最大2本です。
   3本目を押し込まず、ノード群の間隔を広げて右側・下側に空間を確保し、再配線します。
   図全体を単純に移すだけでは間隔が増えないため、ノード間の空間も広げます。

4. **赤同士の交差は禁止する。赤とオレンジは長い迂回の場合だけ交差を許可する。**
   赤・オレンジが区間として重なる配線は、共通ノードの記号内を除いて禁止します。
   赤とオレンジの点交差は、交差なしの候補が次のいずれかに該当する場合だけ許可します。
   - 交差ありの候補の2倍以上の長さになる。
   - 4グリッド以上余計に迂回する。
   - 検査した配線領域に交差なしの経路がない。
   許可した接続ごとに、交差なし・交差ありの候補長と理由を記録します。
   灰色の補酵素接続などは、この赤同士・赤とオレンジの交差条件の対象外です。

5. **TCA輪郭から、無関係な線を1グリッド以上離す。**
   輪郭の内側・外側とも対象です。実際にTCAノードへ接続する最初の直線部分だけを例外とします。
   接続部分という理由で反対側の輪郭に再接近したり、輪郭に沿って近接配線したりすることは許可しません。
   TCA回路自身の円弧・辺は、距離制約の対象外です。

6. **TCAの形と順序を保つ。**
   円形の直径は約12.75から約8.49グリッドへ縮小しました。前版の約2/3です。
   9代謝物・9反応の18ノードを円周上に置き、各ノードのx座標かy座標を整数に合わせます。
   複数のオレンジ接続が集まるTCAノードには、格子点を選びます。
   `--tca-shape square`で四角形も選べます。
   内部への通常ノード・補酵素の配置は許可していますが、接続と距離の検証に通る候補だけを採用します。
   `--tca-interior forbid`で従来の内部配置禁止に戻せます。

7. **交換反応の外周と直線配置を保つ。**
   赤・オレンジ・灰の全線を交換反応の外周内に収めます。交換反応へは内側から接続します。
   対応が確かな`EX_a_e → a_e → a_c`を、実在する主輸送反応も含めて一直線に並べます。
   元モデルに対応する細胞内種がない場合は作らず、2点を直線配置します。
   e_coli_coreでは12組の3点・2組の2点、計38区間を保存後にも検証します。

## 必須条件の範囲で改善する項目

8. **線の長さと曲がり角を減らす。**
   長い迂回を避ける交差候補を比較します。必要な空間を確保した後、使わない外周余白を縮小します。
   余白縮小は全制約を検証し、オレンジ総配線長が増えない場合だけ採用します。
   同一反応の物理的な共有区間は、総配線長では1回だけ数えます。
   有限探索であり、全配置の最短性や最小面積を証明しません。

9. **最後に表示を整える。**
   SVG・PNG・Escher・SBML Layoutで同じ配線を使います。ノード内の接続口を覆う記号も表示に反映します。
   保存された実際の線を再構築し、重なり・距離・交差・外周・元モデルの保持を検査します。

## 実行順序

1. 小さくしたTCAと、主要経路のノードを配置する。
2. 赤の配線を先に決め、赤同士の交差を検査して固定する。
3. グリッド線上の交換反応の直線通路を確保する。
4. 混雑時は右・下へノード群を押し広げ、オレンジを配線する。補助通路は最大2本とする。
5. 長い迂回に対してだけ、赤との点交差を許可する。
6. 灰色の接続もTCAとの距離を保って配線する。
7. 必要な間隔を残したまま、使わない外周の余白を縮める。
8. 保存後の全配線を再検証する。

円形の生のオレンジ重なりも0です。四角形は記号内の接続に0.5グリッドの共有部分があり、記号外は0です。

既定は`--crossing-policy adaptive-grid`です。
従来の厳密な赤交差禁止モードは`--crossing-policy red-hard`、従来描画は`--crossing-policy legacy`で選べます。
